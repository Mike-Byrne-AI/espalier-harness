**Don't break:** `ESPALIER_MEMORY.md` (repo root) is the *hot* index; this folder is the *cool* overflow. One topic per file, with a one-line summary + link back from a `ESPALIER_MEMORY.md` row. Entries cross-link with `[[wikilinks]]`. These files ARE the project's records — provenance and history belong here; don't strip them.

## Before writing or editing in this folder:

1. Read [`README.md`](README.md) — when to add a file here and the categorized-memory convention.
2. Keep each file single-topic; put the one-line summary + link in `ESPALIER_MEMORY.md`, not the full body in the index row.
3. Link related entries with `[[slug]]` so the accumulated judgment stays navigable.
