| `DEF-590` | scripts/wheel_smoke.py::locate_wheel | The wheel smoke test selects the lexicographically last wheel in `dist/` and calls it the newest, so in a persistent `dist/` a leftover build outranks the one just produced. Driven at HEAD: the function returns `sorted(dist_dir.glob(...))[-1]`, and that sort puts the `0.8.0a9` filename after `0.8.0a13`. Who: the maintainer running the wheel smoke against a `dist/` that was not emptied, who is told the current build passed when a stale artifact was the one installed and exercised. Fix shape: select by parsed PEP 440 version rather than by filename order, and print the wheel actually chosen so the artifact under test is named in the output. | minor |
