| `DEF-2082` | tools/cc/hooks/_bash_patterns.py::_cmd_program_at (a word before cmd's switch) | **A recursive delete cmd runs behind a word that is not a switch before its `/c` draws no refusal on either shell tool: `cmd foo /c rd /s /q .` (PowerShell) and `cmd foo //c rd /s /q .` (Bash) are plain allows, and so is a switch glued to a word (`cmd x/c rd /s /q .`), while `cmd /c rd /s /q .` is refused.** Found while fixing DEF-2080's stop-parsing token between switches (win, 2026-11-13); driven in process at the lane's head and in the export of HEAD alike, so the lane neither caused nor closed it. Echo-only drives from Git Bash show cmd takes its program after the first `/c` or `/k` outside double quotes, at the start of a word or glued to one after a single slash, and skips every word before it: `cmd foo //c echo RAN`, `cmd x y z //c echo RAN`, `cmd -x //c echo RAN` and `cmd "a b" //c echo RAN` print RAN, and so do `cmd x/c echo RAN` and `cmd x/k echo RAN` (the code review of DEF-2080's lane, re-driven by win), while a doubled slash glued to a word is no switch (`cmd a//c echo RAN` starts an interactive cmd) and a quoted one is skipped (`cmd "a //c echo Q" //c echo RAN` prints RAN alone). Cause: `tools/cc/hooks/_bash_patterns.py::_cmd_program_at` walks switches only and returns no program at the first word that is not one, so all three of its readers (the delete reader and the harness-variable check through `iter_cmd_programs`, and Start-Process's argument-list read) see an interactive cmd. The `--%` word is this class's first instance closed: DEF-2080's lane steps over it up to a `/` glued to it (`cmd --%x /c` and `cmd --%x/c` are read); every other word is not. Who is hurt: an operator whose agent writes a cmd delete with a stray word before the switch, or a switch glued to one, which then removes the tree unasked. Contract basis: a catastrophic delete (`.` and a drive root), one literal wrapper (cmd's program); nothing declares it a limit. Fix shape: walk words to the first `/c` or `/k` outside double quotes, word-initial or glued after a single slash, ending at the outer statement's end by that shell's grammar (the walk is shared by both shells today and ends at either shell's separators), with wall rows on both tools and an echo row per skipped-word spelling. The probe prints how many programs the PowerShell reader reads for `cmd /c echo x`, `cmd foo /c echo x`, `cmd -x /c echo x` and `cmd x/c echo x` (`1 0 0 0` while the defect stands). | major | LOGIC_BUG | ADOPTER |
