| `DEF-2087` | tools/cc/hooks/_bash_patterns.py::_PS_POSITIONAL_RE (a redirect before the PowerShell positionals read by pattern) | **The PowerShell positional readers that work by pattern read a redirect written before the operands as the first positional, so a write into a protected zone, or a move of a dotenv, with the redirect first is allowed (`Set-Content 2>$null tools/cc/hooks/write_guard.py x`, `Add-Content` the same, `Copy-Item 2>$null b.py tools/cc/hooks/write_guard.py`, `Move-Item 2> err.txt tools/cc/hooks/write_guard.py b.py`, `Move-Item 2> err.txt .env b.txt`, `Move-Item 2>&1 .env b.txt`), where each spelling with the redirect last is refused and every Bash twin denies.** `tools/cc/hooks/_bash_patterns.py::_PS_POSITIONAL_RE` (the write verbs) and `tools/cc/hooks/_bash_patterns.py::_PS_COPY_MOVE_POSITIONAL_RE` (copy and move, read by `tools/cc/hooks/_bash_patterns.py::_candidate_paths_from_powershell` and `tools/cc/hooks/_bash_patterns.py::iter_ps_removed_or_relocated_operands`) take their positionals by pattern, not through a token reader, so the redirect-free step DEF-5108 gave the token readers does not reach them. The same reading reaches past the first positional (DEF-5108's second code review, driven): a redirect between the operands (`Copy-Item a.py 2>$null tools/cc/hooks/write_guard.py`), `Out-File 2>$null` before its zone file, and a merge after a valued flag (`Set-Content -Path 2>&1 tools/cc/hooks/write_guard.py -Value x`) are each allowed; and a redirect in git's global-option slot (`git 2>$null clean -fdx`, `git 2>$null rm cc/x.json`) is allowed on both tools, so that shape is the git arms' as well. Found by the failure-mode review of DEF-5108's lane; driven through the wired hook on that lane's tree (the six allowed, the redirect-last controls refused). Who is hurt: an operator whose agent writes a redirect ahead of its operands on the PowerShell tool, an unusual spelling, and so writes into the harness's own zone, or moves a dotenv, unrefused. Contract basis: the anti-self-disable floor (a write into the harness's own zone) and the secret read, plain syntax. Fix shape (probable): read these verbs' positionals through a token reader and `tools/cc/hooks/_bash_patterns.py::_ps_redirect_free`, or teach the patterns a redirect run ahead of a positional, with a PowerShell oracle per verb; the pattern work, and an oracle of its own, are why it is not DEF-5108's. The probe prints the zone write leg for the redirect-first `Set-Content` and the secret leg's move for the redirect-first `Move-Item` (`False False` while the defect stands). | minor | LOGIC_BUG | ADOPTER |
