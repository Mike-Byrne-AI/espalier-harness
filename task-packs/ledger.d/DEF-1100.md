| `DEF-1100` | tools/cc/hooks/subagent_stop.py::_changed_markdown; tools/cc/hooks/subagent_stop.py::_relief_payload; tools/cc/hooks/stop_gate.py (Gate 2 docs-refresh evidence); tests/test_subagent_stop.py | **Stop-gate Gate 2 treats any dirty markdown in the whole working tree as proof that the `docs-maintainer` subagent refreshed docs, so a docs-maintainer that wrote nothing is credited with the parent session's own edits.** When the `docs-maintainer` stops, `tools/cc/hooks/subagent_stop.py::_changed_markdown` records `git status --porcelain -- *.md`, the tree's dirty-markdown set at that moment, as `changed_docs`, and `_relief_payload` stores it in the relief record. Gate 2 relieves whenever that list is non-empty. Any markdown the parent edited before dispatching the agent (a task pack, a README, a record doc) therefore relieves an agent that changed no file; the record has no snapshot from before the run, so it cannot tell the two apart. This is the attendance-relief shape DEF-495 set out to close, and it contradicts the shipped HOOKS and TROUBLESHOOTING text that Gate 2 needs a docs-maintainer run that changed docs. The shipped test (`test_records_changed_markdown`) dirties the file before the hook runs, so the conflation is built into the test rather than caught by it. The session's `write_count` counts source writes only, never markdown writes, so Gate 2 has no second signal either. Found by the 2026-10-03 adoption audit (`espalier-issues/audits/2026-10-03-adoption/public_report.md`, C-5); re-checked at `08ab2db`: LIVE (the audit scoped this to the whole-tree conflation; session-wide relief and name-only Gate 3 relief are documented design, not part of this row). The agent-roster configuration, the `*.md` pathspec that misses other doc extensions and the Python-shaped reviewer bodies are DEF-963's; this row is the remainder, the attribution of the evidence to the agent's own run. Who is hurt: an adopter whose session dirtied markdown and then dispatched `docs-maintainer`, which found nothing to do; the docs gate clears and the nudge to refresh docs is lost. Fix shape: snapshot the dirty-markdown set (paths with mtimes or hashes) at SubagentStart for the mapped agent, record at SubagentStop only the paths that are new or changed since, and change the test to dirty the file before the agent starts and have the agent change nothing. | minor | LOGIC_BUG | ADOPTER |
