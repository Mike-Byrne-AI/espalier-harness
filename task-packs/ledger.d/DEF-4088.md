| `DEF-4088` | tools/cc/hooks/_zone_watch.py::tracked_dirs (the index's spelling is compared byte for byte: NFD and case-only names prune) | **`tools/cc/hooks/_zone_watch.py::tracked_dirs` names a tracked directory by the bytes git prints and `snapshot` compares them to the walk's spelling byte for byte, so on a filesystem that folds case or normalizes Unicode a tracked self-ignoring directory whose two spellings differ is pruned as generated, in every session.** The set (lines 236-270 as of b9824291) is the index's spelling; the compare is `base not in tracked` (361) over the name `os.walk` returns. Measured on this box on 2026-11-01 (APFS, `core.ignorecase=true`, `core.precomposeunicode=true`), two edges: a force-added directory whose name is written in NFD: the index prints NFC, the disk holds NFD, `tracked_dirs` holds the NFC name and `snapshot` kept nothing under it; a force-added `zone/Gen` renamed on disk to `zone/gen`: `git status` is clean, `tracked_dirs` holds `zone/Gen` and `snapshot` kept nothing. `os.path.normcase` folds on Windows only (`normcase('Zone/GEN')` is unchanged here), so a fold cannot come from it on macOS. Twin: `espalier/zone_writes.py::_stats` (205-235), the same compare at 232. Who is hurt: the adopter on macOS or Windows whose generated-but-tracked directory carries a non-ASCII name, or was renamed in case alone: a slip write into it is unreported, and the index never changes its spelling on its own, so no later session recovers it. Fix shape: compare by stat identity (`os.path.samefile` of the index's path and the walked one), or fold case where git's `core.ignorecase` is true and NFC-normalize where `core.precomposeunicode` is true, on both twins; pinned by a test for each edge, skipped where the filesystem does not fold or normalize. Why no probe: the output differs by platform. On a case-sensitive, non-normalizing filesystem neither edge can be laid (an NFD name stays NFD in the index, and a case-only rename is a different directory), so no one open value holds across the matrix; the fix's test is the oracle. | minor | LOGIC_BUG | ADOPTER |
