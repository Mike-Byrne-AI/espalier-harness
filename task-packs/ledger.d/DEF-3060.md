| `DEF-3060` | tools/cc/hooks/_bash_patterns.py::_PS_NATIVE_WRAP_RUN, ::_PS_REMOVE_WRAP_RUN (the wrapper run crosses a PowerShell brace separator: quadratic) | **The PowerShell readers run the Bash wrapper run under PowerShell's own separators, where a brace opens a script block anywhere, so a wrapper argument holding braces is read again from every brace inside it and the readers go quadratic: `"env -x a{}" * n` reads about 400 ms at 8 KB through `tools/cc/hooks/_bash_patterns.py::_PS_REMOVE_ITEM_RE` on base and about 500 to 740 ms since, fourfold per doubling.** `::_PS_NATIVE_WRAP_RUN` and `::_PS_REMOVE_WRAP_RUN` compose `::_CMD_POS_WRAP_ONE_LOOSE` (before the DEF-3043/3044/3053 lane, `::_CMD_POS_WRAP_RUN`) behind `::_PS_CMD_POS`, whose separators include `{` and `}`; the Bash anchor makes a brace a start only at a word's start (DEF-3044), so its word classes keep braces past the first character, which in PowerShell crosses a start.
