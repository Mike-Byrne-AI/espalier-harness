| `DEF-2106` | tools/cc/hooks/session_start.py::_box_lock_note | **Nothing tells a seat that its box lock is a path other than the box's: once `ESPALIER_BOX_LOCK` is set, the banner's box-lock note says nothing, whatever the path, so a seat still on a private lock path never sees the other seats' tiers or the box's slot count.** `tools/cc/hooks/session_start.py::_box_lock_note` returns '' as soon as the variable is set, and only an unset variable earns the off-note. `tools/cc/seat.py`'s launch keeps a path the shell already set (`env.setdefault`, and the PowerShell and POSIX launch lines alike). Who: a PC seat still on the private path the interim ruling gave it (air's 8318e9, 2026-11-18) after DEF-2105's count file is written beside the box's default lock: relaunched from the same shell, it keeps its own path, takes no slot from the box's file, and its tiers run past the count beside the other seat's, a serial leg beside a pool included (DEF-4062's shape). The timing reds that follow read as code faults, and on Windows CP-KILL's box-lock reading cannot see the other seat's holder. A stray `ESPALIER_BOX_LOCK` opens any box this way, the Air included, so DEF-2105's "a stray export cannot open the Air" holds for the count and not for the path. Found by DEF-2105's failure-mode review (finding 4) and confirmed by reading; placed by air (1cc329) and filed unassigned in DEF-2105's lane. Fix shape (the review's): where `ESPALIER_BOX_LOCK` is set and its normalised absolute path differs from `seat.py::box_lock_default()`, the note says `box lock: this seat locks <path>, not the box's <default>`, pinned by one banner test; a seat that meant its own path still reads the line, which costs one line and blocks nothing. The probe sets the variable to another path and prints the note. | minor | HYGIENE | OPERATOR |
