| `DEF-3026` | tools/cc/ship.py::_classify (a failed step decides before any note or log is read) + tools/cc/ship.py::status | **`ship.py status` reads a required cell that failed on the runner's own disk as the diff's red and prints `fix, push, rebind`, so a seat is sent to fix a diff that is green.** `tools/cc/ship.py::_classify` returns `("decided", "a step failed")` for any job whose conclusion is `failure` with a failed step, before it reads a note or a log, and `status` prints `required red: <cells> -- fix, push, rebind`.
