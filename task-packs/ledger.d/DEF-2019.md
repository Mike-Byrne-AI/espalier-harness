| `DEF-2019` | espalier/doctor.py::_probe_wired_hooks_start (the per-hook retry after a batch timeout) | **`doctor`'s wired-hook start probe retries every hook alone when its one batch probe misses its 20 s budget, so on a slow host it can spend 20 s plus 20 s per wired hook and then report every hook as unable to start.** `espalier/doctor.py::_probe_wired_hooks_start` imports every wired hook in one bounded child (`_run_start_probe`, `_HOOK_START_BUDGET_S` = 20); when that child does not answer, it probes each hook in a child of its own with the same 20 s, and reports each that does not answer as "did not answer within 20 s". With the twelve canonical hooks the worst case is 13 spawns, 260 s, before the doctor's other checks; driven with the spawn stubbed to miss, the probe makes 13 bounded calls. A batch that misses on a slow host says the host is slow, not that any one hook cannot start: on windows-latest, where a concurrently spawned interpreter took 31 to 73 s to start (`DEF-1130`), each single-hook child can miss as well. Observed: run 38888957685 (job 116933506700), a windows-latest cell, ended its session at 33 minutes with pytest-timeout's stack inside this probe, under `tests/test_contract_consumers.py::TestDoctorReadsRequiredFromContract::test_doctor_required_includes_contract_required`; whether it had reached the per-hook loop is not read (the run's merge commit is gone). Who is hurt: an adopter on a slow Windows machine who runs `doctor`, the diagnostic the README sends them to after an upgrade, waits four minutes and is told that every guard fails to start while all of them run; and a test that runs the doctor whole, which on a slow runner outlives any per-test ceiling below that. Fix shape: one deadline for the whole probe, or no per-hook retry after a batch that timed out (a timeout names the host, not a hook; the per-hook pass is for a batch that answered with a failure that hid its siblings). The probe stubs the spawn to miss, wires twelve hooks and prints the spawns the probe would make and their budget: `13 spawns, 260 s` while open. | minor | LOGIC_BUG | ADOPTER |
