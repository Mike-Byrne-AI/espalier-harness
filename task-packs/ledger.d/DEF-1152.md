| `DEF-1152` | tools/cc/hooks/_integrity.py::tail_audit (today's UTC log file only), read by tools/cc/session_resume.py::_print_audit_tail (/status --log); tools/cc/hooks/session_start.py (reads no audit record); tools/cc/hooks/config_guard.py::_run_main (records configchange_policy_settings_kill_switch_detected, a type in no family /status --log lists) | **A record that is a hook's only voice reaches the operator only if `/status --log` runs on the same UTC day, and one such record is never shown at all.** Since this class closed, an exit-0 fault with no channel to Claude is said once a session through `tools/cc/hooks/_hook_utils.py::say_once`, which writes an audit record, and that record is the one trace. Its only reader is `/status --log` (`tools/cc/session_resume.py::_print_audit_tail`), which reads through `tools/cc/hooks/_integrity.py::tail_audit`, and that opens the log file named for today's UTC date only; the SessionStart hook reads no audit record. Separately, `tools/cc/hooks/config_guard.py::_run_main` records a kill-switch arriving in managed policy settings as `configchange_policy_settings_kill_switch_detected`, a type in none of the families `/status --log` lists (refusals, pauses, maintenance bypasses, fail-open), so it is never shown, although a policy `disableAllHooks` is the change that silences every other hook. Driven 2026-10-06 on a temp root with `ESPALIER_AUDIT_DIR` set: a fail-open record written today is counted by `/status --log` (the control); the same record dated yesterday is not, the SessionStart banner names neither, and a policy record written today is not named. Separate from the not-reach this class declares (ConfigChange's silent block of a project change).
