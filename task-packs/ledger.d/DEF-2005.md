| `DEF-2005` | tests/test_verify_pins.py::_SESSION_CHURN_PREFIXES (root-relative); tests/test_verify_pins.py::TestIsolation::test_a_run_does_not_touch_the_live_tree | **A test that walks the live tree reads a sibling seat's worktree under `.claude/worktrees/<name>/` as part of this checkout, so that seat's live session reds it on a box where seats share a clone.** `tests/test_verify_pins.py::TestIsolation::test_a_run_does_not_touch_the_live_tree` snapshots every file of the checkout by (size, mtime) and exempts session churn by root-relative prefix (`::_SESSION_CHURN_PREFIXES`: `cc/blueprints/` and `.espalier-state/`, the `DEF-663` fix); a linked worktree's own `.espalier-state/last_tool` and `tool_call_count`, rewritten on every tool call by the seat working there, sit under `.claude/worktrees/2/` and are not exempt. Seen 2026-10-14 on the Windows box (main checkout, win-2's live session in `.claude/worktrees/2`): the test redded naming exactly those two files and passed on the next run with the sibling quiet. The same walk-into-a-sibling shape redded ten live-tree rows on 2026-10-09 (held candidate `2e61b6926c3b`); this is the class's first filed member. Who: a maintainer running the full tier in a main checkout while another seat works in a worktree under it, who reads a red that names no change of theirs. CI has no worktree. Fix shape (untested): leave registered linked worktrees (`git worktree list`) out of every live-tree walk, or exempt session churn at any depth under `.claude/worktrees/`. The probe asks the module's own predicate whether a sibling worktree's session file is churn, and prints True while it is not. | nit |
