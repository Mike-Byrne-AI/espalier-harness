| `DEF-523` | scripts/sync_github_workflow_asset.py::main (the uncommitted-root refusal branch) | A second sync is refused while the root copy is dirty from the script's own first run, because nothing records what the script wrote. Driven at HEAD: the refusal fires on `asset differs from root` plus a non-clean `_root_file_status()`, and the module holds no digest or stamp of its own output — the refusal text itself concedes the case, telling the reader that if the root file is only the output of an earlier run then `--force` is the correct move. Who: the maintainer who edits the asset, syncs, edits the asset again and syncs again without committing in between, and is told their own generated file may carry a hand edit. Fix shape: record a digest of the bytes the sync writes and treat a dirty root matching it as safe, so only genuine root-side content requires `--force`. | minor |
