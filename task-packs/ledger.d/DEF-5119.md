| `DEF-5119` | tools/cc/hooks/_speedbump.py::_kill_targets (a redirect's stream digit read as a pid) | **The kill checkpoint reads a redirect's stream number as a pid: a stop of one process with a stderr redirect on the line names process 2 beside it, on Bash wherever the redirect sits and on PowerShell where the redirect comes before the pid.** `tools/cc/hooks/_speedbump.py::_kill_targets` takes each word `tools/cc/hooks/_speedbump.py::_statement` hands it, and the stream digit of a spaced or glued redirect arrives as a digit word, read as a pid like any other operand; DEF-5108's redirect-free step reached the token readers of the write leg, not this one. Found by the failure-mode review of DEF-2087's lane and read in process there: Bash `kill 4242 2> err.txt` names [2, 4242], PowerShell `Stop-Process 2> err.txt 4242` names [2, 4242], and the PowerShell redirect-last spelling names [4242]. Who is hurt: an operator whose agent stops one of its own strays with the not-found message silenced, on a box where process 2 is another seat's or the kernel's: the checkpoint judges a process the command never names (whether that draws a nudge was not driven; process 2 is a kernel thread on Linux and usually absent on macOS). Contract basis: a speed bump (the kill checkpoint, whose job is to judge the processes a kill names), plain syntax. Fix shape (probable): read the kill's words through the redirect-free step, a redirect and its target dropped before the pid list is read, with a row per tool. The probe prints the pids the Bash and the PowerShell spellings name (`[2, 4242] [2, 4242]` while the defect stands). | nit | LOGIC_BUG | ADOPTER |
