| `DEF-3037` | tools/cc/ship.py::_handoff_push (the records-ref park tried only with no pull request open); tools/cc/ship.py::_park_the_row (whole-diff test and base reset) | **A handoff onto an open pull request pushes its Session Log row even when the row is all the push carries, so the lane's running full tier is cancelled and starts again for a record.** `tools/cc/ship.py::_handoff_push` parks a rows-only handoff on the seat's records ref (`tools/cc/ship.py::_park_the_row`, `DEF-5007`) only when no pull request is open for the branch; with one open it merges the base in (`::_merge_base_first`), folds the parked rows (`::_fold_session_log`) and pushes, and the new head cancels the run in progress (`.github/workflows/test.yml` sets `cancel-in-progress` for the test and test-serial jobs). The dispatcher's 11-04 run review read 56 of 196 pull-request test runs from 10-30 to 11-03 superseded by a later push: 29 catch-ups, 12 handoff rows pushed onto an open pull request, 4 folds of parked rows and 11 fixes. The rows and folds are this row, 16 runs as a floor: a handoff push that merges the base in reads in that census as a catch-up. A catch-up the board's `stale:` line asks for cancels by design, so CI tests the combination. Who is hurt: every seat whose lane is in CI when its handoff lands, whose merge waits another full tier for a commit no test reads, and the runners the restarted tier holds.
