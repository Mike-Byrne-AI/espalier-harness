| `DEF-3022` | tools/cc/hooks/_integrity.py::_prune_old_audit_logs (no time bound of its own; the scan in name order) | **`tools/cc/hooks/_integrity.py::_prune_old_audit_logs` reads the first line of up to `_MAX_PRUNE_SCAN` (5,000) audit logs at every SessionStart with no time bound of its own, in name order, so a home audit store past a few thousand logs cuts the banner at its 13 s wall inside the prune.** `tools/cc/hooks/session_start.py`'s boot table calls it bare (the `audit log pruning` phase), and the wall (`_WALL_SECONDS`, DEF-3015) cuts the start there: the warnings after it and the session, permissions, pull-request, mail and orders lines never run. Measured on the Windows box on 2026-11-01: `~/.espalier/audit` held 5,695 logs, 108 of them past 30 days by mtime; a read-only first-line pass over 5,000 took 11.7 s; a phase-timed run of the hook that `tests/test_adopter_generic_systems_fire.py::TestTheBannerCarriesTheAdoptersPrinciples::test_the_startup_banner_lists_the_adopters_titles` drives reached the prune at 0.22 s and was cut there at 13.0 s, so the test reds on every run on that box (green on CI's empty store). The scan sorts by name, `<slug>-<YYYYMMDD>.log` (`audit_path`), which orders by repository slug, not age, so a time bound on that order alone would reread the same first slugs every start and never reach an old log late in the alphabet. The store fills from harness runs that drop the test's store: two test sites build a child env from `os.environ` minus every `ESPALIER_*` name, which drops conftest's per-test `ESPALIER_AUDIT_DIR` (`tests/test_adopter_generic_systems_fire.py::_hook_env`, `tests/test_recall.py`'s init run), and `tools/cc/check_ledger_probes.py::_outside_the_launching_session` hands every probe the launcher's env, so a probe driving a hook site writes under its temp tree's slug (about 40 `tmp*` slugs on 2026-11-01). Who is hurt: an adopter on Windows, or any slow disk, whose audit store has grown past about 5,000 logs gets every SessionStart banner cut in `audit log pruning`; and this box's full tier, red on the banner test every run. Fix shape: the prune reads the oldest name date first and stops at a deadline the hook passes inside its own budget, saying on the banner when it stopped with logs named before the window still unread; the test and probe envs keep a tmp `ESPALIER_AUDIT_DIR`. The probe drives the prune in process over 300 seeded logs with each first-line read slowed 10 ms and a 0.5 s deadline (a base without the keyword falls back to the bare call) and prints whether it ran past 2 s: True while open.
