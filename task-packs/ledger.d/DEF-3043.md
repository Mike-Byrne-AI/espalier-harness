| `DEF-3043` | tools/cc/hooks/_bash_patterns.py::_CMD_POS_WRAP_RUN (a wrapper flag's argument does not decline an assignment word: exponential on a repeated pair) | **The command-position anchor reads a repeated wrapper flag followed by an assignment word in time exponential in the repeat count, so a command of a few hundred bytes wedges every anchored arm of the PreToolUse guard past the hook's timeout, and the call then runs unjudged.** In `tools/cc/hooks/_bash_patterns.py::_CMD_POS_WRAP_RUN` a wrapper flag's optional argument (`[^-\s;\|&][^\s;\|&]*`) declines a wrapper word and a bare digit by two lookaheads, the comment's own ReDoS rule, and does not decline an assignment word, which `::_CMD_POS_ENV_ASSIGN` also reads under `::_CMD_POS_NO_VERB`'s star: `env -i A=1` parses as the flag `-i` with the argument `A=1`, or as the flag alone and then the assignment, so n repeats have 2^n partitions on a failing match. Driven in-process at `272ba769` with `re.compile(_CMD_POS + "zzz")` on `"env -i A=1 " * n + "x"`: 0.6, 9.8 and 160 ms at n = 8, 12 and 16 (176 bytes), doubling per repeat; `"sudo -u A=1 "` and `"env -i A=/x "` read the same. Every `_CMD_POS`-anchored arm carries it: the speed bump's fetch arms at `272ba769` read 1.2 s at n = 16 of `"env -i bash <( env -i A=/curl "`. `tests/test_redos.py::test_cmd_pos_linear_on_repeated_prefix_run` repeats each prefix token alone (`env -i `, `A=1 `), never the pair, so the population missed it. Who is hurt: an operator whose agent sends a generated command with such a run (judged, never run here): the search holds the interpreter lock, so `write_guard.py`'s time budget cannot refuse it, Claude Code cancels the hook at its 5 s timeout, and a cancelled PreToolUse hook lets the call through with the wall, the nudges and the zone check skipped. Fix shape: a third lookahead on the flag argument declining an assignment word (`(?![A-Za-z_]\w*=)`), as the wrapper word and the digit are declined, so each token has one arm that can own it; and the composed tokens (`{w} -i A=1 ` for each wrapper) in `_prefix_run_tokens`. Found while timing the lane that closes `DEF-3033`.
