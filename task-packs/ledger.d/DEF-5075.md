| `DEF-5075` | espalier/surface_impact.py::build_report (the edited-mirror-source loop) and espalier/pack_manifest.py::parse_pack (the path of a path::symbol entry) | An edit declared the way packs declare a symbol edit, `path::symbol` under Changed-semantics, still names no sync for a mirrored source: `espalier/pack_manifest.py::parse_pack` reduces `tests/conftest.py::_MARKER_RULES` to the bare `_MARKER_RULES`, so `espalier/surface_impact.py::build_report` never sees the path its edited-mirror-source loop reads (that loop answers a bare path only). A pack author who edits a fixture in a mirrored test file, or a function in a mirrored doc's generator, runs the pre-flight and is not told the selfcheck or asset sync must run; the mirror drifts until a full run reds its parity test. Fix shape: keep the path of a `path::symbol` entry beside the symbol in the parsed manifest (an added field, so the symbol consumers stay as they are) and let the edited-mirror-source loop read it. The probe drives `build_report` on a pack declaring `tests/conftest.py::_MARKER_RULES` under Changed-semantics and prints False while no obligation names `sync_selfcheck_tests.py`. | minor |
