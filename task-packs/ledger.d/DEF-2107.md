| `DEF-2107` | tools/cc/hooks/_speedbump.py::_box_lock_paths (the launcher's old box-lock default, moved by four readers each with its own copy) | **Four readers move the launcher's old box-lock default onto the home file, each with its own copy of the rule, so the next change to where the lock lives can move three and miss one, and the reader it misses sees no holder.** The producer, `tools/cc/seat.py::box_lock_default`, names `~/.espalier/espalier-box.lock`, but a shell can still export the launcher's old default (the lock's name under the temp folder), and `seat.py launch` keeps an inherited value. Four readers treat that old path as the home file, each in its own way: `tests/_box_lock.py::current_path` and its copy `scripts/guard_cost_census.py::current_path` join the temp folder and move it; `tools/cc/hooks/_speedbump.py::_box_lock_paths` reads the home file beside any path bearing the lock's name; `tools/cc/hooks/session_start.py::_same_lock` joins the temp folder at each call and compares. The home file is spelled again beside the producer, in `tests/_box_lock.py::home_default`, `scripts/guard_cost_census.py::home_default` and inline in `_box_lock_paths`. Only pins hold them together (`tests/test_box_lock.py` for the banner, `tests/test_guard_cost_census.py` for the census copy, `tests/test_speedbump_kill.py` for CP-KILL), and no one function owns the rule. Contract basis: CP-KILL is a speed bump, a kept job (docs/HOOKS.md), and on Windows the box-lock holder record is its only reading, so a reader that misses the moved path drops the nudge; the slip it nudges was recorded on 2026-10-31, when one seat killed another's tier as a stray of its own. Who is hurt: the seat whose tier is killed after the next box-lock change edits three of the four readers, when CP-KILL or the banner misses a live holder. Fix shape, untested: one home beside `tools/cc/_json_safe.py::box_lock_slots` for both halves (the home file and the old default's move) that each reader calls, the tests' and the census's copies included, so the oracle reads the product's rule.
