But `espalier init` deploys `tools/cc/` and `tools/cc/hooks/` on every adopter, and `espalier` is importable from the session interpreter. The agent also tells the adopter to `Edit this file directly`, but the file carries the managed marker and the next `init` overwrites the adaptation without saying so.
