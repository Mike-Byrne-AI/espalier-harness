| `DEF-5108` | tools/cc/hooks/_bash_patterns.py::_ps_removal_target_tokens (a redirect among the PowerShell effect reader's tokens) | **The PowerShell effect reader reads a stream's redirect and its target as operands, so a rename or an archive whose stderr goes to a log named like a dotenv is refused as a read of that log (`Rename-Item notes.txt b.txt 2> .env.err`, `Compress-Archive notes.txt a.zip 2> .env.err`), where its Bash twin (`mv notes.txt b.txt 2> .env.err`) runs.** `tools/cc/hooks/_bash_patterns.py::iter_ps_removed_or_relocated_operands` reaches `tools/cc/hooks/_bash_patterns.py::_ps_removal_target_tokens`, which keeps every token that is not a flag, redirects included; the secret leg reads that reader's moves and archives as reads (`_SECRET_EFFECTS`). The Bash reader drops a redirect and its target wherever they stand (`tools/cc/hooks/_bash_patterns.py::_operands`). Found by the failure-mode review of DEF-5107's lane, which gave both secret-read legs one redirect predicate and left this sibling reader, which needs its own PowerShell oracle per arm (rename, archive, native destroy), to a row of its own; read in-process on that lane's tree. Who is hurt: an operator whose agent renames or archives a file on the PowerShell tool with stderr sent to such a log, refused for a write. Contract basis: the secret-read leg, plain syntax. Fix shape (probable): take each redirect and its target out of the reader's tokens before the arms read them, with the predicate DEF-5107's lane gave the secret legs, and one relief row per arm with a pwsh oracle. The probe prints the read leg for both spellings (`True True` while the defect stands). | minor | LOGIC_BUG | ADOPTER |
