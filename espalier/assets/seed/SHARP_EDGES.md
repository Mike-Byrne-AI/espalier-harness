# Sharp Edges

Things this repo trips on or will trip on. Each entry should prevent a
specific mistake. Categorized long-form footgun docs live in
[`docs/sharp-edges/`](sharp-edges/).

> Espalier seeded this file near-empty as a starting point. It is yours —
> unmarked, refreshed on re-init only while it still matches the copy it was
> deployed from, otherwise left exactly as you left it, and safe to rewrite
> completely.
> Two things fill it in:
>
> - `/analyze` grounds the harness on your codebase and updates this file
>   as patterns and footguns surface.
> - `/debug` reads it first when something breaks, so an edge recorded here
>   is an edge the next session does not have to rediscover.
>
> It ships near-empty on purpose: a sharp edge is only useful when it names
> a footgun *this* repo actually has. Generic advice copied in from
> elsewhere costs a read and prevents nothing.

## Add your first sharp edge here

A sharp edge = the footgun + the mistake it prevents + a one-line way to
prove you have hit it. Write one the first time something surprises you —
that is the moment the detail is still in your head.

Delete this placeholder section once you have a real one.
